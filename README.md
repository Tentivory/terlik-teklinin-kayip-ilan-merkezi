# Terlik Teklinin Kayip Ilan Merkezi

Bu depo, ev icinde sistematik olarak kaybolan **tek terligin** resmi kayip ilanini ureten bilimsel, idari ve tamamen gereksiz bir protokoldur.

Diger terlik oradadir. Sen onu gormezsin. Yazilim gorur.

## Neden var?

Cunku:

1. Cift terlik teorisi evrenin temel sabitlerindendir.
2. Tek kalan terlik sessiz bir diplomatik krizdir.
3. "Az once buradaydi" cumlesi hukuken delil sayilmaz ama duygusal olarak kesindir.
4. Patates yoktur. Bu onemlidir.

## Kurulum

```bash
python3 terlik.py
```

Parametreli:

```bash
python3 terlik.py --sahip "Ayse" --renk "bordo" --taraf sol
```

Calisir. Cikti verir. Terligi getirmez. Getirmesi de beklenmez.

## Resmi ilkeler

- Bagirma yasaktir.
- Koltuk altina bakmak bir arama yontemidir, hakaret degil.
- Bulunan terlik alkislanmaz.
- Kayip ilani 7 ev gunu gecerlidir, sonra evren sifirlar.
